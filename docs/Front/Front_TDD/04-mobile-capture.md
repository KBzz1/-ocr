# 前端 TDD — 手机端任务上传

> PRD: PR-FE-002
> 关联: `05-page-management.md`
> 任务状态见 `docs/Shared/state-enums.md`

| ID | 类型 | 用例 |
|----|------|------|
| FE-CAP-001 | 组件 | URL 含有效 `task_id` 和上传令牌时，请求任务上传状态并显示已上传图片数量 |
| FE-CAP-002 | 组件 | 任务不存在或令牌无效时显示"无效的上传链接，请重新扫描二维码"，禁用拍摄和上传 |
| FE-CAP-003 | 组件 | 非 `uploading` 任务显示只读完成/处理中提示，禁用继续上传和完成上传 |
| FE-CAP-004 | 组件 | 点击单个"拍照/选择图片"触发文件输入或相机入口，选取图片后直接进入上传流程 |
| FE-CAP-005 | 组件 | 单个文件入口可选取 jpg/jpeg/png/bmp 图片并显示本地待上传状态 |
| FE-CAP-006 | 组件 | 选择非图片文件时前端拦截，显示"不支持的文件类型"，不调用上传 API |
| FE-CAP-007 | 组件 | 图片超过限制时前端拦截，显示图片过大提示，不调用上传 API |
| FE-CAP-008 | 组件 | 上传中显示 loading/进度状态，重复点击不产生重复请求 |
| FE-CAP-009 | 组件 | 上传失败保留失败项，显示"上传失败，请重试"与重试入口 |
| FE-CAP-010 | 组件 | 点击重试后只重新上传失败图片，不重复上传已成功图片 |
| FE-CAP-011 | 组件 | 未上传任何图片点击"完成上传"时提示至少上传一张图片，不调用 finish API |
| FE-CAP-012 | 组件 | 已上传图片后点击"完成上传"，调用 `POST /api/mobile-upload/{taskId}/finish` |
| FE-CAP-013 | 组件 | 完成上传成功后页面切换为只读完成态，提示到电脑端查看 |
| FE-CAP-014 | 组件 | 上传成功后列表显示缩略图或文件名、页序和"已上传"状态 |
| FE-CAP-015 | 组件 | 上传失败项只显示重试/移除本地失败项，不显示补拍/重新框选 |
| FE-CAP-016 | E2E | 360px、375px、390px、414px、428px 移动端视口下主要按钮不遮挡、不溢出 |
| FE-CAP-017 | 组件 | 手机上传页不渲染采集会话状态、过期倒计时、锁定、取消或修订采集入口 |
| FE-CAP-018 | 组件 | 手机上传页不渲染四边形框选页、重新框选、拖拽排序或补拍替换入口 |
