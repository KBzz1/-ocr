# 前端 TDD — 端到端关键路径

## FE-E2E-001：完整上传到人工导出

1. 电脑端打开工作台，显示系统状态和空任务列表。
2. 点击"新建任务"，任务列表新增 `uploading` 任务；弹窗显示任务上传二维码、任务编号和已上传图片数量。
3. 移动端通过任务上传 URL 进入上传页。
4. 选择 3 张本地 fixture 图片并上传成功。
5. 完成上传后手机端提示回到电脑端，任务变为 `processing`。
6. 电脑端任务列表出现任务，状态流转到 `review`。
7. 打开审核页，展示后端成功返回的 OCR 文本和结构化字段候选。
8. 修改字段并保存；统一审核并完成任务。
9. 任务进入 `done`。
10. 触发 JSON 和 Excel 下载，任务状态保持 `done`。

## FE-E2E-002：算法模块失败必须报错

后端返回 `ALGORITHM_MODULE_NOT_CONFIGURED` 时：

- 任务状态为 `failed`。
- 任务列表和详情页显示错误原因。
- 可编辑审核页不可用。
- 页面提供重新处理入口。
- 不出现"人工补录后继续确认/导出"的降级路径。

## FE-E2E-003：离线约束

- 页面不请求外部域名。
- 所有 mock API 使用本地地址。
- 断网不导致前端加载远程资源失败。

## FE-E2E-004：当前 MVP 不覆盖的旧流程

以下旧流程不作为 E2E 正向路径：

- 采集会话创建、过期、锁定、取消或修订采集。
- 四边形框选、重新框选、裁剪或透视矫正。
- 手机端拖拽排序、补拍替换。
- `capturing`、`uploaded`、`ready_for_review`、`confirmed`、`exported` 旧任务状态。
