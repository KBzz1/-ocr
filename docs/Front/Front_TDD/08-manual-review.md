# 前端 TDD — 电脑端人工审核

> PRD: PR-FE-004
> 关联: `09-field-evidence.md`, `10-field-status-confirmation.md`

| ID | 类型 | 用例 |
|----|------|------|
| FE-REV-001 | 组件 | 审核页展示原图、OCR 文本、结构化字段三个区域 |
| FE-REV-002 | 组件 | 单页任务显示该页原图和对应文本 |
| FE-REV-003 | 组件 | 多页任务点击页码或缩略图可切换主图和当前页文本 |
| FE-REV-004 | 组件 | 可切换查看合并 OCR 文本；文本为空时显示后端返回的空状态说明，不崩溃 |
| FE-REV-005 | 组件 | `failed` 任务禁止进入可编辑审核页，展示失败原因和重新处理入口 |
| FE-REV-006 | 组件 | 结构化字段候选来自后端成功结果；前端不得基于 schema 自行生成可审核字段 |
| FE-REV-007 | 组件 | 点击字段值进入编辑态，输入框获得焦点 |
| FE-REV-008 | 组件 | 字段值变化后保存调用 `PUT /api/tasks/{taskId}/review` 或当前实现约定的保存 API |
| FE-REV-009 | 组件 | 保存成功后修改过的字段状态变为 `modified` |
| FE-REV-010 | 组件 | 保存失败后保留用户输入并显示"保存失败，请重试" |
| FE-REV-011 | 组件 | 用户可清空字段值并保存，状态仍由后端返回的 `unreviewed`、`confirmed` 或 `modified` 决定 |
| FE-REV-012 | 组件 | 刷新页面后从审核结果加载人工修改后的值 |
| FE-REV-013 | 组件 | 统一审核并完成时，未修改字段提交为 `confirmed`，已修改字段保持 `modified` |
| FE-REV-014 | 组件 | 完成审核成功后任务状态变为 `done` |
| FE-REV-015 | 组件 | 保存中或完成中按钮进入防重复提交状态 |
| FE-REV-016 | 组件 | 字段值未变化时不触发保存 API 调用 |
| FE-REV-017 | 组件 | 审核页不提供人工新增字段、前端推断字段、确认空值或存疑状态操作 |
