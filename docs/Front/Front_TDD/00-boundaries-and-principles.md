# 前端 TDD — 审查结论与测试总原则

> 基于 `docs/PRD文档/产品PRD.md` 的当前 MVP 编写。
> 共享定义见 `docs/Shared/state-enums.md`、`docs/Shared/error-codes.md`。

## 审查结论与边界修正

- 手机端扫码上传直接绑定任务，不再设计独立采集会话。
- 手机端只负责拍照/选择图片、多图上传、上传结果展示和完成上传。
- 图片页序按上传成功顺序确定；当前 MVP 不测试拖拽排序、补拍替换或修订采集。
- 当前 MVP 不做四边形框选、重新框选、裁剪、透视矫正或自动边界识别。
- 不测试 OCR/LLM 语义正确性。前端只展示后端成功返回的 OCR 文本、字段候选、来源证据、抽取元数据和人工审核状态。
- 算法模块未配置、异常、空结构化结果或契约非法时必须显示 `failed`，不得进入人工降级流程。
- 所有外部 HTTP 请求必须被 mock 或失败；不得要求运行时联网。

## 本项目前端负责

- 本地工作台展示、新建任务、二维码弹窗和手机上传入口展示。
- 手机端图片选择、类型/大小前置校验、上传状态、失败重试和完成上传。
- 任务列表、MVP 五状态展示、失败重试入口、导出入口。
- 审核页原图/OCR 文本/结构化字段展示、字段编辑、保存、完成审核和来源提示。
- JSON/Excel 导出触发、批量 JSON zip 下载入口、重抽取入口的确认和结果展示。
- 错误提示、离线隐私和无外部网络请求质量门禁。

## 本项目前端不负责

- OCR 文字识别准确率。
- LLM 字段抽取准确率。
- 图像裁剪、透视矫正、去摩尔纹、去反光或自动边界识别。
- 从 schema、OCR 文本或页面内容推断、补造结构化字段。
- 医学诊断、医学建议或字段医学合理性判断。
- 采集会话过期/锁定/取消/修订、四边形框选、拖拽排序或补拍替换。

涉及上述能力时，前端测试只验证：

- 是否按当前 MVP API 契约调用本地后端。
- 外部模块不可用、异常或返回无效结果时是否显示明确错误。
- 后端返回成功结果中的空字段、无来源字段是否可人工审核。
- 旧能力入口不再出现在当前 MVP 页面中。
