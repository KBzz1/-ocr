# 前端 TDD — 电脑端工作台

> PRD: PR-FE-001
> 状态定义见 `docs/Shared/state-enums.md`

| ID | 类型 | 用例 |
|----|------|------|
| FE-WKS-001 | 组件 | `GET /api/system/status` 返回可用时，首页显示本地服务状态、离线运行提示和新建任务入口 |
| FE-WKS-002 | 组件 | 状态接口返回 `error` 时，展示后端错误消息，不渲染误导性的可用状态 |
| FE-WKS-003 | 组件 | 状态接口超时后显示服务无响应，并提供重试按钮 |
| FE-WKS-004 | 组件 | 任务列表为空时显示暂无病历任务的空状态 |
| FE-WKS-005 | 组件 | 最近处理记录为空时显示暂无处理记录 |
| FE-WKS-006 | 组件 | 点击"新建任务"后调用 `POST /api/tasks`，成功后显示任务上传二维码、任务编号和已上传图片数量 |
| FE-WKS-007 | 组件 | 二维码 URL 使用局域网 IP，不使用 `127.0.0.1` 作为手机访问地址；上传令牌不以明文常驻首页 |
| FE-WKS-008 | 组件 | 多网卡或自动识别失败时，在"手机无法连接？"说明中展示排障步骤 |
| FE-WKS-009 | 组件 | 创建任务失败时显示错误提示，且不保留旧二维码 |
| FE-WKS-010 | E2E | 浏览器访问工作台后页面可加载，无 console error |
| FE-WKS-011 | 组件 | 任务统计颜色和中文文案与 MVP 五状态对齐：uploading 上传中、processing 处理中、review 待审核、done 已完成、failed 失败 |
| FE-WKS-012 | 组件 | 首页提醒区失败任务操作文案为"查看原因"或"重新处理"，不向医生展示"查看日志" |
| FE-WKS-013 | 组件 | 从首页侧边栏进入 `/tasks` 后仍保留工作站侧边栏，提供可返回工作台总览的入口 |
| FE-WKS-014 | 组件 | 最近任务列表每项展示任务编号、创建时间、图片数量、状态和主要操作 |
| FE-WKS-015 | 组件 | 工作台不渲染采集会话、剩余时间、取消会话、修订采集、重新框选或拖拽排序入口 |

关键 RED 断言：

- 如果组件把 `127.0.0.1` 放进二维码，FE-WKS-007 必须失败。
- 如果首页常驻展示上传令牌或完整上传 URL，FE-WKS-007 必须失败。
- 如果 `/tasks` 渲染为缺少工作站侧边栏的孤立页面，FE-WKS-013 必须失败。
- 如果页面加载远程 CSS、图标、字体或图片资源，FE-SEC-001 必须失败。
- 如果任务统计展示旧状态，FE-WKS-011 必须失败。
