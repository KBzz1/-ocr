# 前端 TDD — 四边形框选收敛

> 当前 MVP 不做四边形框选、重新框选、裁剪、透视矫正或自动边界识别。

| ID | 类型 | 用例 |
|----|------|------|
| FE-QUAD-001 | 组件 | 图片选择通过校验后直接上传原图，不进入框选页面 |
| FE-QUAD-002 | 组件 | 上传请求不携带 `quad_points`、裁剪坐标或处理后图片路径 |
| FE-QUAD-003 | 组件 | 已上传图片列表不渲染"重新框选"入口 |
| FE-QUAD-004 | 组件 | 前端 API client 不调用更新 `quad_points` 的旧接口 |
| FE-QUAD-005 | E2E | 手机上传主流程不出现 "调整识别范围"、"框选区域" 或四角拖动控件 |

禁止断言：

- 禁止断言裁剪后图片像素内容。
- 禁止断言摩尔纹、反光、倾斜被修正。
- 禁止断言自动识别边界准确。
- 禁止断言前端根据图片内容自动生成框选结果。
