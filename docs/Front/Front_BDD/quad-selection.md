# 四边形框选收敛说明

> 当前 MVP 不做四边形框选、重新框选、裁剪、透视矫正或自动边界识别。手机端只上传原图；图片质量问题建议新建任务重新上传。

```gherkin
Feature: 四边形框选移出当前 MVP
  作为 产品维护者
  我想要 从当前前端行为契约中移除四边形框选
  以便 后续开发不再把旧框选流程当作待实现需求

  Scenario: 手机端选择图片后直接上传原图
    Given 我在手机上传页选择一张图片
    When 图片通过前端类型和大小校验
    Then 前端应直接调用图片上传 API
    And 不应进入 "调整识别范围" 或四边形框选页面
    And 上传请求不应携带 quad_points

  Scenario: 已上传图片列表不提供重新框选入口
    Given 当前任务已有已上传图片
    When 我查看手机端已上传列表
    Then 列表不应显示 "重新框选" 按钮
    And 前端不应调用任何更新 quad_points 的 API
```
