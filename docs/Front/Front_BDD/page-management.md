# 页面列表与页序展示

> 对应 PRD: PR-FE-002 | 依赖: `docs/Shared/state-enums.md`

```gherkin
Feature: 页面列表与页序展示
  作为 手机端上传用户
  我想要 查看已经上传到当前任务的图片列表
  以便 确认图片数量和上传结果后完成上传

  Scenario: 连续上传多页后页面按上传成功顺序编号
    Given 我在手机上传页依次上传了 3 张图片
    When 我查看已上传图片列表
    Then 列表应该显示页序为 1、2、3
    And 每页应显示上传成功状态、缩略图或文件名

  Scenario: 上传失败图片不占用最终页序
    Given 第 1 张图片上传成功
    And 第 2 张图片上传失败
    When 我查看已上传图片列表
    Then 成功图片仍显示为第 1 页
    And 失败图片应显示失败状态和重试入口
    And 后续成功上传的图片应按成功顺序继续编号

  Scenario: 完成上传后列表进入只读态
    Given 我已点击完成上传
    When 我再次查看手机上传页
    Then 已上传列表可以只读展示
    And 不应出现删除、拖拽排序、补拍替换或重新框选入口

  Scenario: 图片质量或页序错误时建议新建任务重新上传
    Given 我发现已经完成上传的图片顺序或质量有误
    When 我查看手机上传完成态
    Then 页面应提示回到电脑端处理
    And 当前 MVP 不提供原任务内补拍、替换、排序或修订采集路径
```
