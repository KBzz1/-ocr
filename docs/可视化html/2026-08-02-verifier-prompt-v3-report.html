OCR 认错字

系统把病历照片变成文字，机器认字偶尔会认错。比如"粗测"被读成"粗侧"，"回流征"被读成"回流证"。

例：双眼粗测视力正常 → 双眼粗侧视力正常
🔍

复核器 = 自动检查员

从病历里抽出的每个字段（心率、体格检查、用药……）再让 AI 过一遍，发现可疑就在字段上贴一张"请医生重点看"的标签。

贴了标签的字段 → 进人工审核页
📏

校准 = 验收考试 + kappa = 打分

检查员标得准不准，得考试：拿一批字段让它标，再找权威（这里用 AI 模拟医生）逐条裁判"该不该标"。裁判和检查员意见越一致，分越高。

kappa：0~1 的分数，0.7 及格才能上岗

3这次干了什么：给检查员换"说明书"
检查员是 AI，行为由一份"说明书"（prompt）决定。我们按你的两个决定改了它，改一版考一次试，共三轮。
第 1 版（v2）你的决定 1：去掉"爱找茬"性格

删掉"每个字段都要主动挑毛病"的要求，改成"只做事实核对，没毛病就说没毛病"。同时保留并写明了"标记 OCR 认错字"这个职责。

结果：矫枉过正——295 个字段只标了 1 个，等于检查员罢工了。真实存在的错字（"粗侧""回流证"）一个都没标。

第 2 版（v3）修复：长字段拆句 + 错字模式清单

找出罢工原因：体格检查这类字段特别长（几百字），AI 扫一眼觉得"整体通顺"就放行了。改成把长字段拆成一句一句让它逐句看，再给它一份常见错字模式清单（叠字"舌舌"、近形字"扣及/扪及"等）。

结果：能标出问题了（11 处），但离及格还远。

每次考试怎么考3 个 AI 质检员 × 295 个字段

每版都跑 6 份真实病历（本地 Qwen 模型，每轮约 15 分钟），产出 295 个字段的检查结果；再派 3 个 AI 质检员，像医生一样逐条判断"这个字段该不该标"，算一致性打分。

它抓到的，和它误报的（真实例子）

✅ 真抓到了（v3）

"粗侧""回流证""舌舌""齿辅"这类 OCR 错字，跨多个病历被标出。

原文：双眼粗侧视力正常
应为：双眼粗测视力正常
⚠️ 误报 1：把正常词当错字

"鼻翼无煽动"是正常医学表述（鼻翼、煽动都是规范词），检查员却标了可疑。

🧑‍⚕️ 有意思的案例：AI 没医生懂

检查员发现"脉搏 99 次/分但心率 108 次/分"标了可疑——表面看是矛盾。但裁判（模拟医生）知道：这病人是房颤，脉搏本来就跟心率不齐，这是正常现象，不该标。这类判断只有懂医学的才能做。

最大的短板：漏网之鱼太多

该标出的 32 处里只标出 6~7 处（约两成）。原因：OCR 错字变体太多——同一处错读在不同病历里可能长成"粗侧""相测""粗测"三种样子，检查员记不住所有变体，说明书里写了的模式它有时也对不上号。这就像让人背字典，永远背不全。

5结论与下一步
  • 你的两个决定都验证有效：去掉对抗后误报从 30 处降到 4 处（医生的信任不再被消耗）；"标记 OCR 认错字"成为检查员的明确职责且能干活。
  • 但整体还不能上岗：漏报太多，kappa≈0.2 远低于 0.7 门槛。现在让它自动进医生工作流，反而漏掉真问题，比没有它还危险。
  • 保持现状：复核器继续"不上岗"（不自动接入），和之前的处理一致。三版实验数据全部存档，随时可复查。
  • 未来可选方案：把长字段拆成句子后每句强制判定（漏网之鱼无处可藏），能把召回做上去，但要改动检查员和考试工具的一整套约定，工程量大。等需要时再做。

    OCR / 字段 / 抽取

    OCR：把照片里的字变成电脑文字的程序。会认错字，尤其手写体和模糊的字。

    字段：病历里的一个个格子，比如"心率""体格检查""既往史"。

    抽取：从一整段病历文字里，把每个格子该填的内容自动填好。

    复核器 / 标可疑 / verdict

    复核器：抽完字段后再用 AI 检查一遍的自动检查员。发现可疑就贴标签，让医生在审核页重点看。

    标可疑（suspicious）：贴"请医生重点看"的标签。通过（pass）：没问题。失败（fail）：问题严重。

    verdict：检查员对每个字段给出的结论（通过 / 可疑 / 失败）。

    校准 / kappa / 上岗线

    校准：给检查员"验收考试"——拿真实病历让它标，再找权威逐条裁判它对不对，算一致性。

    kappa：检查员和裁判的意见重合度，0~1。0.7 以上算高度一致（上岗线）；0.4 以下基本等于各说各的。

    上岗：检查员合格后，才允许自动接入医生日常工作流。

    误报 / 漏报 / 召回

    误报：没问题的字段被贴了标签（虚惊一场，消耗医生信任）。

    漏报：有问题的字段没被贴标签（漏网之鱼，比虚惊更危险）。

    召回：该抓的问题抓到了几成。两成 = 10 个真问题只抓到 2 个。
