# superpowers 历史归档

本目录保存当前 MVP 收敛前的阶段性 spec、plan 和设计记录。归档内容只用于追溯历史决策，不作为当前产品需求、BDD/TDD 断言、API 契约或实施计划。

当前产品口径以以下文档为准：

- `docs/PRD文档/产品PRD.md`
- `docs/PRD文档/PRD任务清单.md`
- `docs/Shared/`
- `docs/Front/Front_BDD/`、`docs/Front/Front_TDD/`
- `docs/Backend/Backend_BDD/`、`docs/Backend/Backend_TDD/`
- `docs/superpowers/specs/` 和 `docs/superpowers/plans/` 中未归档的 MVP 收敛后文档

归档内容中的采集会话、会话过期/锁定/取消/修订采集、四边形框选、重新框选、拖拽排序、补拍替换、旧任务状态和 `quad_points` 契约，不再作为当前 MVP 的正向需求。
