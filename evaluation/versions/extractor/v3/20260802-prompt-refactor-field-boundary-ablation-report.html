1四步消融怎么走的

改动分四步，每步独立提交、独立跑实验，防止"几个改动混在一起说不清是谁的功劳/过错"。

step 0 · 基线旧 prompt 全量结果（已有资产）

抽取指标 + 295 条复核 verdicts。就是前一轮 verifier v3 实验的产物，本次只确认、不重跑。

step 1 · 重构两个 commit

两段 prompt 统一骨架：角色 → 任务 → 输出契约 → 通用原则 → 领域规则 → 固定字段表。一条规则只写一次：删掉"再次强调"整段复读、把 OCR 风险提示压成通用原则一条、错读模式列表 8 例砍到 3 例、"必须可逐字定位"从 3 处合并成 1 处。产出变体 A（纯 system+user）与变体 B（user 末尾加一句"请严格遵守 system prompt 中的【输出契约】【通用原则】【领域规则】。"）。

step 2 · 重跑实验A / B 各跑一次

变体 A 与 B 全量各跑一遍 + 各生成一份 verdicts，和基线对比、互相对比。结论见第 3 节。

step 3 · 加字段边界一个 commit

各加一句话：抽取侧"字段边界：每个字段只抽取字段表对应部位/项目的内容；字段表未收录的内容（一般情况：发育/营养/体型/神志/表情/体位）不写入任何字段"；复核器侧"字段越界 → 标记 extraction_mistake"。不做新字段、不改切分逻辑。

step 4 · 再验证选定形态全量重跑

在选定的形态 A 上重跑全量 + 生成 verdicts，重点看越界是否归零、指标是否回退。结果见第 4/5 节。

ℹ️ 统计口径说明

"发育"命中胸部/乳房字段属于合理内容（胸廓发育、乳房发育就是该部位查体内容）；"神志/表情"命中神经查体字段也是合理内容（神志本来就是神经查体项目）。这两类不计入真越界。

ℹ️ 剩余的两个长值（205/204 字）

pe_eyes 已不含一般情况，但个别病例把外耳道/鼻腔/扁桃体（眼耳鼻口连排）也写进了眼部字段——部位相邻混入。本次边界明确"不做"（不新增字段、不改切分逻辑），列观察项。

6结论与待办
  • 瘦身达成：两段 prompt 各减约 1/3（抽取 7199→4788、复核器 2988→2027 字符），规则一条只写一次，结构统一为 6 段骨架。
  • 指标未回退：重构后与基线差异全在噪声带宽内；越界句加入后 value（84.54%）与幻觉数（17）还往好里走。
  • 复核器标记 11 → 2：中性核验 + 只标记确凿问题，医生人工核验负担大幅下降。
  • 字段越界显著修复：真越界 8 → 2（pe_eyes 4/6 → 0/6，最长 909 → 205 字）；残留为神经查体 2 个短越界 + 部位相邻混入观察项。
  • 形态选 A：B（尾部提醒句）无数据依据，按宁少勿滥取默认；开关保留。
  • 待办：① 人工评价导出 → 官方 kappa 收尾（评价页已交付，等评完）；② 部位相邻混入观察；③ 多行诊断输出质量（重构删了"编号分行"约束，已恢复一句话并在实验外留意）。
